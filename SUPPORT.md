# Support

For setup questions and non-sensitive bugs, open a GitHub issue using the
provided templates. Include your Foist version, Node.js or Docker version, and
sanitized logs.

Never post Slack tokens, OpenAI API keys, real private messages, or unredacted
personal data. Security issues should be reported privately as described in
[SECURITY.md](./SECURITY.md).

Foist is a small open-source project maintained on a best-effort basis.
