# Code of conduct

Foist should be fun without turning people into targets. Project spaces should
be welcoming, constructive, and respectful.

Contributors and maintainers agree to:

- discuss ideas and mistakes without harassment or personal attacks;
- avoid publishing private messages, credentials, or personal information;
- use invented or consenting examples for tests and evaluation data;
- keep jokes aimed at writing patterns, not a person's identity or ability; and
- accept good-faith moderation intended to protect the community.

Maintainers may edit or remove content, close contributions, or restrict
participation when behavior conflicts with these expectations. Report conduct
concerns privately through a GitHub security advisory when public discussion
would expose or further harm someone.
