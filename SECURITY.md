# Security policy

## Supported versions

Security fixes are provided for the latest tagged release.

## Reporting a vulnerability

Please use GitHub's private security-advisory form for this repository. Do not
open a public issue for a suspected vulnerability, and do not include real
Slack messages, workspace credentials, model-provider API keys, or other people's
personal data in a report.

Include a concise reproduction, the affected version, and the likely impact.
You should receive an acknowledgement within three business days. Please allow
a reasonable remediation window before public disclosure.

## Deployment responsibility

Self-hosted operators are responsible for protecting their Slack and model-provider
credentials, restricting access to the Foist data volume, applying updates, and
following the data-handling requirements of their organization.
